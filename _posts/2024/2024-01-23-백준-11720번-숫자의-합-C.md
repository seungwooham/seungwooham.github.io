## 문제:

N개의 숫자가 공백 없이 쓰여있다. 이 숫자를 모두 합해서 출력하는 프로그램을 작성하시오.

## 입력:

첫째 줄에 숫자의 개수 N (1 ≤ N ≤ 100)이 주어진다. 둘째 줄에 숫자 N개가 공백없이 주어진다.

## 출력 :

입력으로 주어진 숫자 N개의 합을 출력한다.

## 풀이:

```cpp
#include <iostream>
using namespace std;

int main(){
    int N;
    int sum=0;
    string numbers;
    
    cin>>N;
    cin>>numbers;
    
    for (int i=0; i<numbers.length(); i++){
        sum += numbers[i]-'0';
    }
    
    cout<<sum;
    return 0;
}
```

각 문자에서 문자 `'0'`(ASCII 코드 48)을 빼서 숫자 값으로 바꾸는 것이 중요한 아이디어로 보인다.
