## 문제

N×N개의 수가 N×N 크기의 표에 채워져 있다. (x1, y1)부터 (x2, y2)까지 합을 구하는 프로그램을 작성하시오. (x, y)는 x행 y열을 의미한다.

## 입력

첫째 줄에 표의 크기 N과 합을 구해야 하는 횟수 M이 주어진다. (1 ≤ N ≤ 1024, 1 ≤ M ≤ 100,000) 둘째 줄부터 N개의 줄에는 표에 채워져 있는 수가 1행부터 차례대로 주어진다. 다음 M개의 줄에는 네 개의 정수 x1, y1, x2, y2 가 주어지며, (x1, y1)부터 (x2, y2)의 합을 구해 출력해야 한다. 표에 채워져 있는 수는 1,000보다 작거나 같은 자연수이다. (x1 ≤ x2, y1 ≤ y2)

## 출력

총 M줄에 걸쳐 (x1, y1)부터 (x2, y2)까지 합을 구해 출력한다.

## 풀이

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(NULL);
    cout.tie(NULL);
    
    int size, query;
    cin>>size>>query;
    
    vector<vector<int>> org(size+1, vector<int>(size+1, 0));
    vector<vector<int>> sum(size+1, vector<int>(size+1, 0));
    
    for (int i=1;i<=size;i++){
        for (int j=1;j<=size;j++){
            cin >> org[i][j];
            sum[i][j] = sum[i][j-1]+sum[i-1][j]-sum[i-1][j-1]+org[i][j];
        }
    }

    for (int i=0;i<query;i++){
        int x1, y1, x2, y2;
        cin>>x1>>y1>>x2>>y2;
        int result = sum[x2][y2]-sum[x1-1][y2]-sum[x2][y1-1]+sum[x1-1][y1-1];
        cout<<result<<"\n";
    }
    return 0;
}
```

배열의 크기를 size+1로 하는 것이 코드 작성에 큰 도움이 된다. 예외 처리 없이도 결과가 잘 나오는 모습을 볼 수 있다.
